# Quora Posts CRUD

A simple **CRUD web application** built with **Node.js, Express.js, and EJS**.

### Features

* Create posts
* View all posts
* View individual posts
* Edit/update posts
* Delete posts
* UUID-based post IDs

### Tech Stack

* Node.js
* Express.js
* EJS
* UUID
* Method Override
* HTML/CSS

### Run Locally


Open `http://localhost:3000/posts`.
